# Java

Runnable examples and notes for Java programming fundamentals.

- [OOP](OOP/README.md): classes, encapsulation, inheritance, polymorphism, abstraction and interfaces.
- [Collections](Collections/README.md): List, Set, Map, Queue, generics and comparators.
- [Exception Handling](ExceptionHandling/README.md): checked/unchecked exceptions, custom exceptions and resource handling.
- [Multithreading](Multithreading/README.md): threads, synchronization, executors and concurrent utilities.
- [DSA](DSA/README.md): data structures, algorithms and problem-solving patterns.

Use a JDK 17+ unless an example specifies otherwise.
