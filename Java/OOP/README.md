# Java OOP

## Concepts
1. **Encapsulation:** hide mutable state and expose validated operations.
2. **Inheritance:** derive a specialized class from a base class where the relationship is genuinely an “is-a”.
3. **Polymorphism:** use a common interface while allowing different runtime implementations.
4. **Abstraction:** expose essential behavior while hiding implementation details.
5. **Composition:** build an object from collaborating objects; often preferable to deep inheritance.

## Example
Run `javac Encapsulation.java && java Encapsulation`.

The example stores money in integer paise to avoid floating-point rounding in this small demonstration.
