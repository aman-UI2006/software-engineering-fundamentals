# C++

Runnable examples and notes using C++17 unless otherwise stated.

- [OOP](OOP/README.md): classes, encapsulation, inheritance, polymorphism and RAII.
- [STL](STL/README.md): containers, iterators, algorithms, templates and smart pointers.
- [Exception Handling](ExceptionHandling/README.md): exceptions, custom types and exception safety.
- [Multithreading](Multithreading/README.md): threads, mutexes, condition variables and futures.
- [DSA](DSA/README.md): data structures, algorithms and problem-solving patterns.

Compile with `g++ -std=c++17 -Wall -Wextra -pedantic Example.cpp -o example`.
