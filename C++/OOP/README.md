# C++ OOP

## Concepts
- Classes, objects, constructors and destructors
- Access control and encapsulation
- Inheritance and composition
- Runtime polymorphism using virtual functions
- Abstract interfaces
- RAII and the rule of zero

Use a virtual destructor in a polymorphic base class when derived objects may be deleted through a base pointer.

Run `g++ -std=c++17 -Wall -Wextra -pedantic Encapsulation.cpp -o encapsulation && ./encapsulation`.
