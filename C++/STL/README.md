# C++ Standard Template Library (STL)

## Suggested learning order
1. Sequence containers: vector, array, deque, list
2. Ordered associative containers: set, map, multiset, multimap
3. Unordered containers: unordered_set and unordered_map
4. Adapters: stack, queue and priority_queue
5. Iterators and range-based loops
6. Algorithms: sort, reverse, lower_bound, upper_bound and binary_search
7. Lambdas, custom comparators and templates

Understand iterator invalidation and each container's ordering and complexity guarantees.

Run `g++ -std=c++17 -Wall -Wextra -pedantic STLExample.cpp -o stl_example && ./stl_example`.
